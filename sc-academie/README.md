# SC Académie — лендинг (прототип дизайна)

Продающий лендинг для онлайн-школы французского языка **SC Académie**.
ЦА — русскоговорящие, живущие во Франции и желающие улучшить французский для быта, работы и интеграции.

> Тексты, цены, имена преподавателей и отзывы — **рыба/плейсхолдеры**, их нужно заменить на финальный контент.

## Стек — HAT

| | Для чего |
|---|---|
| **H**TMX | Ленивая подгрузка отзывов (`hx-trigger="revealed"`), «Показать ещё», отправка формы заявки без перезагрузки |
| **A**lpine.js | Мобильное меню, табы программ, мини-тест уровня, переключатель тарифов, FAQ-аккордеон |
| **T**ailwind CSS | Вся стилизация; дизайн-токены в `tailwind.config.js` |

## Структура страницы

1. Hero — оффер, CTA «Бесплатный пробный урок», цифры доверия
2. «Знакомо?» — боли ЦА (префектура, врач, работа, страх говорить)
3. Программы (табы): Повседневная жизнь / Работа / Интеграция и экзамены (DELF, TCF, натурализация)
4. Мини-тест уровня → передаёт уровень в форму заявки
5. Как проходит обучение — 4 шага
6. Почему SC Académie — преимущества
7. Преподаватели
8. Отзывы (HTMX)
9. Цены (помесячно / пакет)
10. FAQ
11. Форма заявки (HTMX)
12. Футер + плавающая CTA на мобильных

## Дизайн

- Палитра по мотивам французского флага, но «мягко»: глубокий синий `ink #14213D`, `bleu #2F55D4`, акцент `rouge #E63946`, кремовый фон `#FBF7F0`.
- Шрифты: **Cormorant Garamond** (заголовки, «французская» элегантность) + **Manrope** (текст). Оба с кириллицей.
- Mobile-first, без горизонтального скролла от 360px.

## Запуск

```bash
cd sc-academie
npm install
npm run build   # собрать dist/styles.css
npm run serve   # http://localhost:8080
```

`npm run dev` — пересборка CSS в watch-режиме. HTMX подгружает `partials/*.html`, поэтому страницу нужно открывать через локальный сервер, а не `file://`.

## Подключение бэкенда

Форма сейчас делает `hx-get="partials/form-success.html"` (заглушка для статики).
Для продакшена замените на `hx-post="/api/lead"` — endpoint должен вернуть HTML-фрагмент (как в `partials/form-success.html`), который HTMX подставит вместо формы.
